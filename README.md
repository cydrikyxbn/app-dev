# The Emperor's New Groove

My favorite movie is **The Emperor's New Groove**! It is a really funny cartoon from *Disney*.

## What happens
There is a mean emperor named **Kuzco** who gets turned into a llama by accident. He has to work with a nice guy named **Pacha** to turn back into a human.
